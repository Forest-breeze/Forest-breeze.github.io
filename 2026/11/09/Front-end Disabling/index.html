Front-end Disabling

  • Background : Front-end restrictions are unreliable.

  • When to use : When copy / paste / right-click / F12 or ctrl +shift +i are not allowed to be used, disable JavaScript.

  • Why would you think of frount-end disabling : Because these functions are all implemented by the webpage in the front end using JavaScript code

  • How to disable JS :

    • For the Edge browser :

    you can choose to type edge://settings/content/javascript into the address bar . Click “Add site”,and paste the URL of the webpage where you want to disable the frontend into the adress bar

    Alternatively, click the three dots in the top-right corner of the Edge browser, select Settings, open ‘privacy,search,and services’ in the left menu, then click JavaScript under ‘Content’, you will see the same page.

    • For the google browser:
      click the three dots in the top-right corner of the google browser, select Settings, open ‘Privacy and security’ in the left menu, then click site settings . Click JavaScript under ‘Content’ , choose “Add” to add the url.

Now you know how to do it !😏🥳
